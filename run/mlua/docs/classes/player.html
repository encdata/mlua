MLua/Player - MLua

Player

Represents a player in the game. Provides methods and properties for player manipulation.

Obtain via: Minecraft:GetService("Players"):GetPlayerByName("Notch")

Type: Player

Properties

Read and write properties on player objects.

player.Name
Read
The player's username.
player.UUID
Read
The player's UUID as a string.
player.Position
ReadWrite
The player's current position in the world.
player.Health
ReadWrite
The player's current health (0-20).
player.MaxHealth
Read
The player's maximum health.
player.Food
ReadWrite
The player's current food level.
player.Saturation
ReadWrite
The player's current saturation.
player.Velocity
ReadWrite
The player's current velocity.
player.Rotation
ReadWrite
The player's rotation (yaw, pitch).
player.ViewMode
ReadWriteClient
The local player's camera perspective. Readable and writable from .client.lua scripts.
player.GameMode
ReadWrite
The player's game mode.
player.Armor
Read
The player's current armor value.
player.IsAlive
Read
Whether the player is alive.
player.IsOnGround
Read
Whether the player is on the ground.
player.IsInWater
Read
Whether the player is in water.
player.IsOnFire
Read
Whether the player is on fire.
Use player:GetPersistentData() for server-saved per-player data and player:GetSyncedData() for replicated values that clients can read. Both return live NBT-style tables.

Methods

Callable methods on player objects.

player:GetName()
Read
Returns the player's username.
player:GetUUID()
Read
Returns the player's UUID.
player:GetUserId()
Read
Returns the player's numeric ID.
player:GetDisplayName()
Read
Returns the player's display name.
player:SendMessage(msg)
Server
Sends a chat message to the player.
player:SendTitle(text)
Server
Sends a title to the player's screen.
player:SendActionBar(text)
ServerClient
Sends an action bar message.
player:Teleport(position)
Server
Teleports the player to a position.
player:GetCFrame()
Read
Returns the player body transform.
player:SetCFrame(cframe)
Server
Teleports/moves the player and applies yaw/pitch from LookVector.
player:GetEyeCFrame()
Read
Returns eye position plus view rotation.
player:GetLookVector()
Read
Returns player forward direction.
player:LookAt(positionOrEntity)
Server
Rotates the player to face a Vector3, Entity, or Player.
player:GetCameraCFrame()
Client
Client-side only; server scripts should use Camera service in client scripts.
player:GiveItem(itemId, count)
Server
Gives an item to the player.
player:ClearInventory()
Server
Clears the player's inventory.
player:Damage(amount)
Server
Damages the player.
player:Kill()
Server
Kills the player.
player:GiveEffect(effect, duration, amp, particles)
Server
Applies a potion effect.
player:RemoveEffect(effect)
Server
Removes a potion effect.
player:HasEffect(effect)
Read
Checks if a potion effect is active.
player:ClearEffects()
Server
Removes all potion effects.
player:PlaySound(name, volume, pitch)
Server
Plays a sound for the player.
player:GetNearbyEntities(radius)
Read
Returns nearby entities.
player:GetNearbyPlayers(radius)
Read
Returns nearby players.
player:GetPersistentData()
ReadServer
Returns the player's persistent MLua data table. Server writes are saved across restarts.
player:GetSyncedData()
ReadServerClient
Returns replicated player data. Server writes sync to MLua clients; client access is read-only.
player:SetData(key, value)
WriteServer
Convenience setter on the player's persistent data table.
player:GetData(key)
Read
Convenience getter from the player's persistent data table.
player:RemoveData(key)
WriteServer
Removes a key from the player's persistent data table.
player:HasPermission(node)
Read
Checks if the player has a permission node.
player:IsOperator()
Read
Checks if the player is a server operator.
