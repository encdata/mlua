MLua/Java - MLua

Java

Direct JVM interop service for loading classes, calling methods, reading fields, and bridging Lua to Java interfaces.

Obtain via: Minecraft:GetService("Java")

Type: Java

Use colon calls for Java instance/static methods from Lua, for example MinecraftClass:getInstance() and screen:getClass():getName(). Static fields and instance fields are exposed as normal property reads, for example mc.screen.
Java reflection works against the runtime environment, not just development names. Some Minecraft internals may use remapped names at runtime, so exact member names are tried first and reflective fallback is used when possible.
MLua keeps raw Java interop available while adding Lua-friendly sugar for arrays, List, and Map. Use direct indexing when you want live access, and use Java:ToTable(...) when you want a detached Lua copy.

Methods

Java:LoadClass(className)
Shared
Loads a JVM class by fully-qualified name. If the name resolves only to a package prefix, returns a package proxy that can be chained deeper.
Java:New(classNameOrClass, ...)
Shared
Constructs a new Java object using a public constructor.
Java:Proxy(interface1, ..., implementationTable)
Shared
Creates a Java proxy implementing one or more interfaces with Lua callbacks.
Java:IsInstance(value, classNameOrClass)
Shared
Returns whether a proxied Java object is an instance of the given class.
Java:Cast(value, classNameOrClass)
Shared
Validates a cast and returns the same live Java proxy when successful.
Java:TypeOf(value)
Shared
Returns the runtime Java class name for a proxied object or class. Returns nil for nil.
Java:GetMethods(classOrObject)
Shared
Returns reflective method metadata entries with Name, Static, ParameterCount, ReturnType, and Descriptor.
Java:GetFields(classOrObject)
Shared
Returns reflective field metadata entries with Name, Static, Final, and Type.
Java:GetEnumConstants(enumClass)
Shared
Returns all constants from a Java enum class as live proxies.
Java:ToTable(value)
Shared
Converts Java arrays, collections, and maps into Lua tables.

Direct Class Example

Load a Minecraft class and read a live field from the client instance.

local Java = Minecraft:GetService("Java")
local MinecraftClass = Java:LoadClass("net.minecraft.client.Minecraft")
local mc = MinecraftClass:getInstance()
local screen = mc.screen

if screen then
    local screenClass = screen:getClass()
    print(screenClass:getName())
end

Package Chain Example

Package proxies can be chained before reaching a final class.

local Java = Minecraft:GetService("Java")
local EntryClass = Java:LoadClass("java").util.Map.Entry
local HashMap = Java:LoadClass("java.util.HashMap")
local map = HashMap:new()
map:put("hello", "world")

Introspection Example

Use reflective helpers when exploring unfamiliar classes.

local Java = Minecraft:GetService("Java")
local ArrayList = Java:LoadClass("java.util.ArrayList")
local list = ArrayList:new()
list:add("a")
list:add("b")

print(Java:TypeOf(list))
print(Java:GetMethods(list)[1].Name)
print(Java:ToTable(list)[2])

Lua Collection Sugar

Arrays, lists, and maps can be used with Lua indexing while staying connected to the live Java object.

local Java = Minecraft:GetService("Java")
local ArrayList = Java:LoadClass("java.util.ArrayList")
local HashMap = Java:LoadClass("java.util.HashMap")

local list = ArrayList:new()
list:add("a")
list:add("b")
print(list[2])   -- b
list[2] = "c"
print(#list)     -- 2

local map = HashMap:new()
map["name"] = "EncData"
print(map["name"])
Java valueLua behavior
Arrayarray[1] is the first element, array[i] = value writes, and #array returns the array length.
java.util.Listlist[1] maps to get(0), writes map to set(index, value), and #list returns size().
java.util.Mapmap[key] maps to get(key), map[key] = value maps to put(key, value), and #map returns size().
Anything elseNormal Java method, field, and property lookup is used.

Live Proxy Behavior

Java values returned to Lua stay connected to the live underlying JVM object.

BehaviorMeaning
Class proxies are liveMethod and field lookup happens when you access them, not when the script first loads.
Object proxies are liveReading mc.screen or calling a Java method uses the current underlying JVM object state.
Reload-safe by referenceReloading a Lua script drops its Lua references, but newly loaded proxies still target the same JVM classes/objects when those still exist.
Generic fallback lookupMLua first tries exact method/field names, then normalized-name reflective fallback for remapped environments such as Minecraft runtime classes.
