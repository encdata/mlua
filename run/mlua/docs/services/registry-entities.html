Registry Entities

Entity and spawn egg registration options. Scripted entities now use a pure Lua AI callback instead of configurable goals. Supports MoveTo, FindNearestPlayer, AttackTarget, persistent data via GetData/SetData, and full world interaction.

Obtain via: Registry.Entities:Register("custom_mob", { attributes = { maxHealth = 40 } })

Type: Registry

AI Callback

Replace the old configurable goals system with a pure Lua AI callback. The AI function receives the entity table every tick and can use built-in methods to control movement, targeting, world interaction, and persistent data.

Registry.Entities:Register("custom_mob", {
    AI = function(self)
        local player = self:FindNearestPlayer(16)
        if player then
            self:AttackTarget(player)
            self:MoveTo(player.PositionX, player.PositionY, player.PositionZ, 1.2)
        end
    end
})
