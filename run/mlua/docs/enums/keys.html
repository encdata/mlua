Keys

Key constants for defaults, rebinding, and input checks.

Obtain via: local jump = Enum.Keys.Space
Use defaultKey = Enum.Keys.Space or any other Enum.Keys.* entry when registering a keybind. You can also pass the raw key string like key.keyboard.space.

Usage

Keys are first-class values for keybind defaults and runtime key changes.

local InputService = Minecraft:GetService("InputService")

InputService:RegisterKeybind("jump", {
    label = "Jump",
    category = "key.categories.mlua",
    defaultKey = Enum.Keys.Space
})

if InputService:IsKeyDown("jump") then
    print("Jump pressed")
end
